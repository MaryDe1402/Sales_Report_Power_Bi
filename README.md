# sales_report_power_bi
A sales analytics dashboard will be introduced, featuring sales trends, identification of top clients and peak sales days, and product category performance. Verification for an additional SQL query has been completed.

## 📊 Key Features & Analysis
*   **Sales Dynamics:** Tracking monthly and seasonal sales trends across product categories.
*   **Client Insights:** Identifying the top performing clients and revenue contributors.
*   **Time-Based Performance:** Analyzing peak sales volume by days of the week.
*   **Product Performance:** Comparing product quantities sold and average pricing.

## 🛠️ Tech Stack & Tools
*   **Data Visualization:** Power BI Desktop
*   **Data Transformation:** Power Query & DAX formulas
*   **Database Queries:** SQL (used for data verification and extraction)
